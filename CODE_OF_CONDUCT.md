# Code of Conduct

## The short version

Be decent to people. This is a small project about putting song lyrics next to code; nobody
needs to have a bad day over it.

## What's expected

- Assume good faith. Most disagreements are misunderstandings about context, not malice.
- Critique code and ideas, not people.
- Accept that maintainers have limited time, and that "no" is a legitimate answer to a
  feature request.
- Respect differing experience levels. A question that seems obvious to you was not obvious
  to the person asking.

## What's not acceptable

Harassment, personal attacks, demeaning comments about anyone's identity or background,
publishing others' private information, sustained disruption of discussions, or any other
conduct that would reasonably make someone unwelcome here.

## Scope

This applies in issues, pull requests, discussions, commit messages, and any other space
where you are participating in this project.

## Enforcement

Report problems by opening a private security advisory or emailing the maintainer listed in
`package.json`. Reports are handled confidentially. Maintainers may warn, edit or remove
contributions, or block accounts, as the situation warrants.

For a fuller treatment of these principles, see the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which this document is aligned with in spirit.
